# Motion Graphics Production Specification: Clinical OS
**Duration:** 20 Seconds
**Format:** 1080x1920 (Vertical/Social) & 1920x1080 (Wide)
**Objective:** High-conversion awareness ad for Clinical OS.

## 1. Creative Direction
The ad uses a "Chaos to Order" narrative. It begins with high-tension, cluttered visuals and resolves into a minimalist, high-tech ecosystem.

## 2. Storyboard & Timing
| Timestamp | Visual | Motion | Text | Audio |
| :--- | :--- | :--- | :--- | :--- |
| 00-04s | Cluttered clinic desk $\rightarrow$ Tablet | Rapid zoom out $\rightarrow$ Implosion | Stop the Chaos. | Ticking $\rightarrow$ Whoosh |
| 04-08s | Isometric Clinic Flow | Path-based animation | Streamline Your Flow. | Rhythmic Electronic |
| 08-12s | Queue Triage Dashboard | Pop-up status changes | Real-time Triage. | Digital Pings |
| 12-16s | Sync: Doctor $\leftrightarrow$ Patient | Mirroring sync effect | Connected Care. | Harmonic Synth |
| 16-20s | Logo Assembly | Geometric construction | Clinical OS. | Final Beat |

## 3. Visual Assets
- **Palette:** 
  - Navy: `#0A192F`
  - Teal: `#00BFA5`
  - White: `#FFFFFF`
- **Fonts:** Inter / Montserrat (Bold)
- **Assets needed:** 
  - Isometric Clinic 3D Model
  - UI Mockups (Booking, Queue, Profile)
  - Vector Logo (SVG)

## 4. Motion Specs
- **Framerate:** 60fps for fluidity.
- **Easing:** Cubic-bezier(0.4, 0, 0.2, 1) for all UI transitions.
- **Transitions:** Morphing and sliding.
